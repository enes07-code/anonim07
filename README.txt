HOSHI: Gothic Rain — Build 04 (assets klasörlü sürüm)

KURULUM
1. ZIP dosyasını tamamen çıkart.
2. index.html dosyası ile assets klasörü aynı ana klasörde kalmalı.
3. index.html dosyasını tarayıcıda aç.

Klasör yapısı:
  index.html
  README.txt
  assets/
    gothic_courtyard.jpg
    walk_0.png ... walk_7.png

Kontroller: WASD veya ok tuşları ile hareket; Shift ile hızlanma. Mobilde ekrandaki yön tuşları kullanılabilir.

Bu paket Build 02'nin assets klasörünü korur ve yağmur zamanlamasını oyun döngüsünün delta süresine bağlar. Bu hâlâ prototiptir; sprite kareleri profesyonel, elle temizlenmiş kare-kare animasyon değildir.
